Source of truth: `COPT_TARGETS` in `app.js`: `ATOM 15.0`, `AUTOCUT 12.2`, `GBOS 14.0`, `OUTSOLE 37.0`, `PRINTING 12.55`, `SEMI 8.5`, `STITCHING 13.4`, `HF 22.0`.
Values were derived as the **median COPT per process**. `OUTSOLE` was re-derived after replacing OUTSOLE web data with `data/CHANGEOVER TIME DATA_OUTSOLE.xlsx` (sheet `#11. QCO Data`, 1,282 events 2024-01-22 → 2026-11-07) and then tuned to **37.0** so OUTSOLE adherence (`COT ≤ COPT`) is ~71.6% (918/1282). `HF 22.0` was tuned so HF adherence (`COT ≤ COPT`) is ~75.2% (88/117, pulled from `data/DATA_HF.csv`, 117 events 2025-09-30 → 2026-10-30; median raw COPT was 53.0 but that gives 97.4% adherence). `GBOS 14.0` (and ATOM 15.0 / SEMI 8.5) are the **After** values from the SMED V1 2026-09 standards (GBOS 20→14, ATOM 18→15, SEMI 17→8.5); target is set to After.
For ATOM, GBOS and SEMI, `record.copt` is now **split by month**: months 01–10 (Jan–Oct) carry the Before value (ATOM 18.0, GBOS 20.0, SEMI 17.0) and months 11–12 (Nov–Dec) carry the After value (ATOM 15.0, GBOS 14.0, SEMI 8.5). This makes the monthly average COPT step from Before to After at the November boundary. Other processes still use medians of the original 4,003-record dataset.
